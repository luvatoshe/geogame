Geogame - обучающая игра по географии


Описание
--------

Geogame помогает изучать географию в игровой форме. Внутри - интерактивная карта мира, флаги и столицы 195 стран, разбитые на 19 уровней с постепенным ростом сложности. Приложение работает как нативная программа на Windows, macOS и Linux, без браузера и без интернета.

Проект написан на Java 21 со Spring Boot и JavaFX.


Возможности
-----------

1. Режим "Страны"
   Интерактивная карта мира, на которой нужно найти названную страну.

2. Режим "Флаги"
   Определение страны по флагу: тест с 4 вариантами, ввод с подсказками, чистый ввод.

3. Режим "Столицы"
   Определение страны по названию столицы и её фотографии.

4. Игровая механика
   - 195 стран в 19 уровнях с накопительной сложностью
   - Динамическое начисление очков в зависимости от времени ответа
   - Система медалей: аметист, жемчуг, золото, серебро, бронза
   - Рейтинг и ранги - от "Новичка" до "Легенды"
   - Отдельный прогресс для каждого игрового модуля
   - Автоматическое сохранение прогресса между сессиями

Архитектура
-----------

Приложение состоит из трёх слоёв:

   JavaFX (десктоп-окно)
        |
        v
   Frontend (JavaScript / HTML / CSS) - игровая логика, карта мира
        |
        v
   Spring Boot (localhost:8081) - REST API, image proxy
        |
        v
   H2 Database (файловая) - таблицы country и level

Ключевые технологии:

- Backend:  Java 21, Spring Boot 4.1, Spring Data JPA, Hibernate, H2
- Frontend: Vanilla JavaScript, HTML5, CSS3, jsVectorMap
- Desktop:  JavaFX 21, WebView, jpackage
- Сборка:   Maven, GitHub Actions

Как играть
----------

В игре три режима, в каждом - три урока:

1. Обучение
   Подсказки включены. Все ответы видны заранее.

2. Практика
   Подсказок нет, но результат остаётся на экране.

3. Экзамен
   Без подсказок, без следов на карте.

Система очков зависит от времени ответа:

   до 10 секунд    - 10 очков
   10-15 секунд    - 9 очков
   15-20 секунд    - 8 очков
   ...
   35+ секунд      - 4 очка (минимум)
   45+ секунд      - проигрыш раунда

Медали:

   Аметист   - все ответы меньше 5 секунд (для флагов и столиц меньше 7)
   Жемчуг    - все ответы меньше 7 секунд (для флагов и столиц меньше 9)
   Золото    - все ответы меньше 10 секунд (для флагов и столиц меньше 12)
   Серебро   - точность не менее 90%
   Бронза    - точность не менее 80%
